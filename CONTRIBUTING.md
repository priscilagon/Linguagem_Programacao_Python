# Como contribuir

Sugestões e correções são bem-vindas!

## Encontrou um erro ou tem uma dúvida?

Abra uma **Issue** descrevendo: a aula ou projeto, o que você esperava e o que aconteceu (copie a mensagem de erro, se houver).

## Quer propor uma melhoria?

1. Faça um **fork** do repositório.
2. Crie uma branch: `git checkout -b minha-melhoria`.
3. Faça commits pequenos e claros.
4. Abra um **Pull Request** explicando a mudança.

## Padrões do repositório

- Código em Python 3, com **4 espaços** de indentação (PEP 8) e nomes em `snake_case`.
- Exemplos devem **rodar sem erros** e usar **dados fictícios**.
- Textos em **português do Brasil**.
- Não inclua senhas, documentos ou dados pessoais reais.
