# Glossário

| Termo | Significado |
| --- | --- |
| Algoritmo | Sequência finita de passos para resolver um problema. |
| Atributo | Dado que pertence a um objeto. |
| Célula | Bloco de um notebook que contém código ou texto. |
| Classe | Molde a partir do qual objetos são criados. |
| Depuração (debug) | Processo de encontrar e corrigir erros. |
| Dicionário | Coleção de pares chave-valor. |
| Função | Bloco de código nomeado e reutilizável. |
| Indentação | Recuo que define os blocos de código em Python. |
| Interpretador | Programa que lê e executa o código Python. |
| Método | Função que pertence a uma classe. |
| Notebook | Documento interativo (.ipynb) com código, texto e resultados. |
| Objeto | Exemplar criado a partir de uma classe. |
| Pseudocódigo | Descrição do algoritmo em linguagem simples, antes do código. |
| Script | Arquivo .py com instruções executadas em sequência. |
| String | Sequência de caracteres; texto. |
| Variável | Nome associado a um valor guardado na memória. |
