# Orientações para os desafios extras – Projeto 5

- **Histórico em arquivo:** gravar um arquivo `movimentos.txt` com `titular;descricao` (modo `"a"`) e carregá-lo para o `historico` de cada conta ao iniciar.
- **Tentativas:** contador `tentativas` no login; `if tentativas == 3: print("Acesso bloqueado.")` e encerrar o fluxo.
- **Tarifa:** em `sacar`, `total = valor + 2.0` e comparar `total > self.saldo`; debitar `total`.
- **Classe `Banco`:** atributo `contas`; métodos `carregar()`, `salvar()`, `criar_conta()` e `login()` no lugar das funções soltas.
