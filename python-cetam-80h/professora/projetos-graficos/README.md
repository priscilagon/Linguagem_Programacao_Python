## Corrigindo o trabalho de um aluno

```bash
python corrigir.py caminho/da/pasta/do/projeto-do-aluno
```

O script roda `testes_logica.py` na pasta do aluno e mostra ✔/✘ por teste. Depois abra `python app.py` e confira a tela. Os arquivos `app.py`, `testes_logica.py` e `ui_comum.py` devem ser os originais (substitua os do aluno se ele os alterou).

O caderno completo, com o gabarito comentado, está em `material/Projetos_Graficos_Caderno_e_Gabarito.docx`.
