# Projeto integrador – Agência Amazônia Tur Digital

Ao longo das 20 aulas você vai construir, passo a passo, o sistema de uma **agência de turismo fictícia** do Amazonas. A cada fase o programa ganha novos recursos, até chegar ao **cofre digital** com cadastro de usuário, login e dados salvos em arquivo.

Destinos usados nos exemplos: **Parintins, Novo Airão, Presidente Figueiredo, Maués** e o **Encontro das Águas**. Todos os valores em reais são **fictícios**.

## Como trabalhar

1. Abra o arquivo da versão em `starter/` e leia os comentários `TODO`.
2. Implemente um `TODO` por vez e **teste a cada passo**.
3. Salve sua versão com um nome próprio (por exemplo, `meu_v1.py`) antes de começar a próxima: cada versão parte da anterior.
4. Use `python tools/simular_entrada.py` para repetir testes sem digitar tudo de novo.

## Regras de negócio principais

- Orçamento limite do cliente: **R$ 1.000,00**.
- Pacotes: **Econômico** (até R$ 800), **Conforto** (até R$ 1.500) e **Premium** (acima de R$ 1.500).
- Dias de viagem válidos: de **1 a 30**.
- Dados de clientes e usuários são gravados em arquivos `.txt` (a partir da Fase 5).
