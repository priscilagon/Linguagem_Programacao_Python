- **Objeto do conhecimento:** estruturas de dados em Python: tuplas e dicionários
- **Habilidade a desenvolver:** aplicar os conceitos de estrutura de dados, organização e acesso de dados, com domínio de conhecimento
- **Avaliação:** formativa

## Resumo da aula

- **Tupla** `( )`: imutável, para dados fixos.
- **Dicionário** `{chave: valor}`: acesso pela chave, como uma ficha cadastral.
- Percorra com `for chave, valor in dicionario.items()`.
- Dicionários podem conter outros dicionários (catálogo de pacotes).
