## O que você vai estudar

- **Objeto do conhecimento:** estruturas de dados em Python: listas; métodos e funções
- **Habilidade a desenvolver:** aplicar os conceitos de estrutura de dados, organização e acesso de dados, com domínio de conhecimento
- **Avaliação:** formativa

## Resumo da aula

- Lista = coleção ordenada e **modificável**, entre colchetes. O índice **começa em 0**.
- Métodos: `append`, `insert`, `remove`, `pop`, `sort`; funções: `len`, `sum`, `min`, `max`.
- Percorra listas com `for item in lista`.
