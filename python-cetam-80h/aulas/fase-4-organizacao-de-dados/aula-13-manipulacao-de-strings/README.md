## O que você vai estudar

- **Objeto do conhecimento:** funções para manipulação de strings
- **Habilidade a desenvolver:** utilizar funções de forma eficaz para manipular conjuntos de caracteres e palavras
- **Avaliação:** formativa

## Resumo da aula

- Métodos: `upper`, `lower`, `title`, `strip`, `split`, `replace`, `find`; função `len`.
- Encadeie métodos: `nome.strip().title()`.
- Validações simples checam apenas o **formato** — use sempre dados fictícios.
