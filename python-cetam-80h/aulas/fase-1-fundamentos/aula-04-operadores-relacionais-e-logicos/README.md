## O que você vai estudar

- **Objeto do conhecimento:** operadores relacionais e lógicos (`==  !=  >  <  >=  <=  and  or  not`); estrutura de um algoritmo
- **Habilidade a desenvolver:** aplicar os conceitos e fundamentos da linguagem de programação
- **Avaliação:** formativa; Calculadora v1 com devolutiva qualitativa

## Resumo da aula

- Comparações resultam em `True` ou `False`. Atenção: `=` **guarda**, `==` **compara**.
- `and` exige as duas condições; `or` basta uma; `not` inverte.
- Todo programa segue **entrada → processamento → saída**.
- A **Calculadora de viagem v1** é a entrega da Fase 1 (veja o projeto integrador).
