## O que você vai estudar

- **Objeto do conhecimento:** comandos de controle de fluxo: `break`, `continue`, `pass`
- **Habilidade a desenvolver:** utilizar comandos de controle de fluxo
- **Avaliação:** AV2 – prática em duplas, com registro de colaboração

## Resumo da aula

- `break` interrompe o laço; `continue` pula para a próxima repetição; `pass` reserva um bloco vazio.
- `while True` + `break` é a base de qualquer **menu interativo**.
- A **AV2** (duplas) avalia funcionamento, validação de entrada, controle de fluxo e colaboração.
