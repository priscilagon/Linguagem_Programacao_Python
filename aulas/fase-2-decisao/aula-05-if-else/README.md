## O que você vai estudar

- **Objeto do conhecimento:** estruturas condicionais: `if`, `else`
- **Habilidade a desenvolver:** explanar as estruturas condicionais e controle de fluxo em Python, demonstrando confiança
- **Avaliação:** formativa

## Resumo da aula

- `if` executa um bloco **somente se** a condição for verdadeira; `else` cobre o caso contrário.
- A **indentação** (4 espaços) define o bloco. Não esqueça os dois pontos `:`.
- Valores fixos ficam em MAIÚSCULAS por convenção: `LIMITE = 1000.00`.
